# YouTube Shorts Content Factory (FREE)

Полностью бесплатный генератор контента для YouTube Shorts, ориентированный на рынки EU и USA.

## 🎯 Возможности

- ✅ **Генерация скриптов** - вирусные темы для фактов, мотивации, технологий
- ✅ **Text-to-Speech** - бесплатное преобразование текста в речь (gTTS)
- ✅ **Создание видео** - автоматическая генерация фона с градиентами
- ✅ **Текстовые оверлеи** - добавление субтитров на видео
- ✅ **Вертикальный формат** - 1080x1920 (идеально для Shorts)
- ✅ **Пакетное создание** - генерация нескольких видео за раз

## 📦 Установка зависимостей

```bash
pip install gTTS moviepy Pillow
```

**Все библиотеки полностью бесплатны!**

## 🚀 Быстрый старт

### Создать одно видео:
```bash
cd content_factory/scripts
python content_factory.py
```

### Создать видео конкретной тематики:
```bash
python content_factory.py facts      # Интересные факты
python content_factory.py motivation # Мотивация
python content_factory.py tech       # Технологии
```

### Пакетное создание (5 видео):
```bash
python content_factory.py batch 5
```

### Пакетное создание по теме (10 мотивационных видео):
```bash
python content_factory.py batch 10 motivation
```

## 🎬 Рабочий процесс

1. **Генерация скрипта** - выбирается случайная тема из базы
2. **Создание аудио** - gTTS озвучивает текст (английский язык)
3. **Генерация фона** - создаётся анимированный градиент
4. **Добавление текста** - накладывается текст с обводкой
5. **Синхронизация** - аудио и видео объединяются
6. **Экспорт** - готовый файл в папке `output/`

## 🔧 Настройка

### Добавление своих тем:
Откройте `content_factory.py` и измените словарь `TOPICS`:

```python
TOPICS = {
    "your_niche": [
        "Your script line 1",
        "Your script line 2",
        # ...
    ],
}
```

### Изменение параметров:
- `fontsize` - размер текста (по умолчанию 70)
- `duration` - длительность видео (автоматически по тексту)
- `color_scheme` - тип фона (gradient/solid)

## ⚠️ Важные замечания

1. **FFmpeg** должен быть установлен в системе (требуется для moviepy)
2. Для создания видео требуется видеокодек `libx264`
3. Первый запуск может занять время (загрузка шрифтов, кодеков)
4. gTTS требует подключения к интернету

## 🆓 Почему это полностью бесплатно?

- **gTTS** - использует Google Translate API (бесплатно, без ключа)
- **MoviePy** - open-source библиотека для редактирования видео
- **Pillow** - бесплатная библиотека для работы с изображениями
- **Нет подписок** - никаких скрытых платежей или лимитов

## 📈 Масштабирование

4. Планируйте публикацию на неделю вперёд
5. Анализируйте статистику и удваивайте успешные форматы

## 🛠️ Troubleshooting

**Ошибка: "No module named 'gtts'"**
```bash
pip install gTTS
```

**Ошибка: "ImageMagick is not installed"**
```bash
# Linux
sudo apt-get install imagemagick

# macOS
brew install imagemagick

# Windows - скачайте с https://imagemagick.org
```

**Ошибка: "ffmpeg not found"**
```bash
# Linux
sudo apt-get install ffmpeg

# macOS
brew install ffmpeg

# Windows - скачайте с https://ffmpeg.org
```
